# Publication scope and provenance

This publication consolidates existing checkpoint content and current project code onto main through a normal merge commit, preserving both histories. Main previously contained only a basic README and an empty index.html; those scaffolds were replaced with navigation. The checkpoint branch is retained. Its sole branch-only project file CHECKPOINT_STATUS.md remains as a clearly historical record. All compatible project code is included; no conflicting unique remote version was found.

Only publication copies were sanitized; local originals were not edited. Scientific protocols/configurations, declared training/sampler RNG seeds, source code, tests and reproducible commands remain. Raw dataset-generation/split seeds, source/realization identifiers, true parameters and protected labels, raw observations, nuisance truths, model binaries, raw posterior chains, private notes, transcripts, task prompts, machine setup notes, caches and huge generated banks are excluded. The five PNGs were inspected for private labels/identities. Aggregate errors/coverage and anonymized case-level convergence/distribution diagnostics are included. Individual-case parameter-error rows are withheld to avoid reconstructing private truth from paired estimates.

Absolute personal paths and contact details are removed from published copies. Some historical reports refer to omitted raw artifacts; those links are marked local-only. Original seal/hash fields are historical provenance, not claims that a sanitized copy has the original hash. PUBLICATION_MANIFEST.json records original and public-copy hashes separately; local seals remain unchanged. Publication does not certify accuracy, real transfer or general calibration.

Intermediate coverage includes original and half training logs, the exact training replay, initial audit findings, conditional continuation and angle repair attempts, prior-sensitivity probe, matched Bayesian failures and accepted refreshes/continuation, rejected thermal PCA128 training, corrected half preprocessing, stress diagnostics and final verification. All failed attempts remain described. The original 96-test archive was already evaluated and is labelled historical; this upload performs no scientific computation or regeneration.

Prompts are removed from the new main tree, but historical commits and the retained checkpoint branch may still contain earlier prompts. History and branches were intentionally preserved.
